# KEN Code Store v4.6.1 — BART Mascot

ต่อจาก KEN Code Store v4.6.0 Admin Neon Dashboard

## เพิ่มในเวอร์ชันนี้
- เพิ่ม Bart mascot ที่แต่งโทน dark-blue / neon ให้เข้ากับธีมเว็บ
- แสดง mascot ใน Welcome Admin Dashboard
- เพิ่ม static assets ที่ `/assets/`
- ระบบเดิมยังคงใช้ฐานข้อมูล `data/` และไฟล์อัปโหลด `uploads/` เดิม

## Deploy
แทนไฟล์ `server.js`, `package.json`, `README.md` และโฟลเดอร์ `assets/` ของเวอร์ชันเดิม
